# Fuentes de las figuras

Montserrat ExtraBold (títulos) y Work Sans Regular y SemiBold (texto), las mismas del visor. Ambas tienen licencia SIL Open Font License 1.1 (`OFL.txt`) y se descargaron de Google Fonts vía Fontsource. `src/figuras.py` las registra en matplotlib; si faltan, usa la fuente por defecto.
